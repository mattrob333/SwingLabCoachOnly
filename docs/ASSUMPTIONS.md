# Assumptions

## Assumption: PRD is authoritative source
**Assumption:** The full SwingLab Web-First MVP document provided by the user is the single source of truth for requirements.
**Why it matters:** Prevents scope creep and contradictory implementations.
**Risk if wrong:** Two engineers build different systems.
**How to validate:** Cross-reference every new feature against the PRD.
**Status:** validated

## Assumption: Web-first is non-negotiable for MVP
**Assumption:** No native apps will be built until the core web loop is proven.
**Why it matters:** Matches guardrails and cost/time constraints.
**Risk if wrong:** Delays paid review loop.
**Status:** validated
