# SwingLabCoachOnly

**SwingLab** — Web-first responsive app for professional baseball hitting coaches.

Fastest workflow for a hitting coach to turn a submitted swing video into a paid, useful lesson in 5–10 minutes.

- Web-first (Android Chrome, iPhone Safari, Desktop)
- No native app required in MVP
- Coach review studio with voice-over + annotations
- AI-assisted lesson pack (coach approves everything)
- Secure parent lesson delivery + follow-up loop

**Status:** Bootstrap phase (Round 1–2 complete)

See `/docs/` for full PRD, tech spec, data model, tasks, and traceability.
